A modern, responsive, and interactive medical healthcare website built with **React** and **React Router**. This project provides a seamless user experience for browsing medical services, booking appointments, and learning about healthcare professionals.

> 🔗 **Live Demo:** [https://zaid-ha-developer.github.io/HealthCar/](https://zaid-ha-developer.github.io/HealthCar/)

---

## ✨ Features

- 🏠 **Landing Page:** An attractive hero section, working process, and testimonials.
- 👨‍⚕️ **About & Team:** Detailed information about the medical platform and its doctors.
- 🩺 **Services & Service Details:** Comprehensive overview of available medical treatments.
- 📅 **Appointment Booking:** An integrated booking navigation system.
- 🔐 **Login Page:** A dedicated authentication UI for users.
- 📞 **Contact Page:** Easy ways for visitors to get in touch.
- ⚡ **Fast & Responsive:** Optimized for desktops, tablets, and mobile devices.
- 🔄 **Seamless Navigation:** Refresh-proof routing using React's HashRouter (optimized for GitHub Pages deployment).

---

## 🛠️ Tech Stack

- **Frontend Framework:** React.js
- **Routing:** React Router DOM (v6)
- **Styling:** Bootstrap 5 & React-Bootstrap
- **Deployment:** GitHub Pages
